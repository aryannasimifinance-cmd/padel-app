# matchy — رزرو زمین و مچ‌میکینگ

وب‌اپ موبایل‌محور برای رزرو زمین **پدل، تنیس، تنیس ساحلی و پیکلبال** در **تهران و کرج**، همراه با مچ‌میکینگ بر اساس سطح بازیکن.

## فلو اصلی (ویزارد)
1. **رشته** — پدل / تنیس / تنیس ساحلی / پیکلبال
2. **نوع** — بازی (حداقل ۲ ساعت) · تمرین (۱ ساعت) · آموزش با مربی · مسابقات آخر هفته · مسابقات رسمی
3. **کجا و کی** — شهر (تهران/کرج) و منطقه، روز، بازه ساعت، مدت — با شمارش زنده باشگاه‌های دارای زمین آزاد
4. **انتخاب** — باشگاه + ساعت آزاد / مربی + ساعت / مسابقه
5. **بازیکن‌ها** — چیدمان روی زمین (پدل همیشه ۴ نفر)، دعوت دوست، و برای جای خالی: **درخواست بازیکن هم‌سطح** که برای همه بازیکن‌های سطوح انتخابی اعلان و آلارم می‌فرستد
6. **مرور و پرداخت** — بلیت، تقسیم هزینه، ثبت نهایی + جشن و امتیاز

سطوح مچ‌میکینگ: `A · B+ · B · B- · C+ · C · C- · D+ · D`

## گیمیفیکیشن
امتیاز تجربه (XP) و رتبه، ۹ نشان قابل باز شدن، جدول رتبه‌بندی شهر، درخواست‌های پیوستن زنده با toast، صدا و لرزش.

## اجرا
```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی در dist/
```

> این نسخه فرانت‌اند است و داده‌ها (باشگاه‌ها، مربی‌ها، مسابقات، بازیکنان) ساختگی هستند و در `src/data.js` قرار دارند. وضعیت کاربر در localStorage ذخیره می‌شود. کد تأیید پیامکی شبیه‌سازی شده است.

## انتشار
با هر push روی `main`، GitHub Actions اپ را روی GitHub Pages منتشر می‌کند (در تنظیمات مخزن: Settings → Pages → Source: GitHub Actions).
